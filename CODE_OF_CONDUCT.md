# Code of Conduct

This project follows the Contributor Covenant Code of Conduct.

## Expected behavior

- Be respectful and constructive.
- Discuss technical tradeoffs with evidence.
- Keep issues and pull requests focused on the project.

## Unacceptable behavior

- Harassment, threats, or personal attacks.
- Publishing private information without permission.
- Repeatedly derailing technical discussion.

Maintainers may remove comments, close issues, or restrict participation when needed to keep the project healthy.
